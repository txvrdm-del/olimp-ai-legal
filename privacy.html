2. Какие данные могут обрабатываться

  • Идентификаторы Discord: ID пользователя, сервера, канала, сообщения; отображаемое имя и роли, необходимые для проверки доступа.
  • Данные мероприятий: выбранные слоты, статусы регистрации, даты участия, предупреждения, исключения, административные действия и начисленные игровые баллы.
  • Обращения к ИИ: текст команд и запросов пользователя и предоставленные им материалы, когда используются ИИ-функции.
  • Технические сведения: журналы работы, ошибки, время взаимодействия и сведения, необходимые для защиты от злоупотреблений.

Приложение не должно получать пароли пользователя от Discord. Объём доступных данных зависит от настроенных разрешений бота и действующих функций.

3. Для чего используются данные

  • Для записи на мероприятия, учёта участников и балансов;
  • для разграничения административных прав и ведения истории операций;
  • для обработки запросов через подключённые ИИ-сервисы;
  • для обеспечения работоспособности, отладки и предотвращения злоупотреблений.
